# מוקד אשקלון

אפליקציה לדיווח על מפגעים בעיר, עם מסך מוקד לטיפול בדיווחים.

- **אפליקציית תושבים:** `index.html`, דיווח עם קטגוריה, מיקום, תיאור ותמונה, מעקב אחרי הדיווחים ומפת מפגעים פתוחים.
- **מסך מוקד:** `admin.html`, רשימה ומפה של כל הדיווחים, עדכון סטטוס והודעה לתושב, עריכת קטגוריות והוספת מוקדנים.
- **נתונים:** Firebase (Firestore + התחברות עם Google), במסלול החינמי. חוקי האבטחה ב-`firestore.rules`.
